## `_short-runs/` —— 中断的启动与试跑

13 条小于 0.5 MB 的 run，按 SB3 原名逐字保留：

| 目录 | 大小 | 说明 |
|---|---:|---|
| `PPO_94` | 0.41 MB | **课程组 run 的第一次尝试**，在 0.995 M 步时中断，随后重启为 `2026-03-18_paper-curriculum-6M`。不要把它当成独立实验。 |
| `PPO_93` | 0.11 MB | 启动探测中最长的一条，0.26 M 步，成功率始终为 0 |
| `PPO_87`–`PPO_92`, `PPO_95`–`PPO_97` | ≤ 0.01 MB | 冒烟测试 / 在前几千步内崩溃 |
| `SAC_1`, `SAC_2` | ≤ 0.01 MB | `2026-04-27_paper-sac-6M` 之前中断的 SAC 启动 |

把它们收进来，是因为一份只记录成功 run 的训练日志算不上日志。

## 曲线 CSV

`benchmarks/tb_curves/` 为上面每一条 run 存放一份抽稀后的 CSV，文件名与 run 目录
**完全相同**，因此曲线与它的 TensorBoard 源可以轻易配对。重新生成：

```bash
python scripts/export_tb_curves.py RL_scripts/body-axis_v2/logs --out benchmarks/tb_curves
```
